Loading & Cleaning Data

Introduction to NumPy/Pandas, loading local and API data, and setting up a clean dataset pipeline.

01 · Intro Python 02 · Loading & Cleaning 03 · Data Analysis 04 · Visualization

This part focuses on importing data and cleaning it up. I pulled stock prices from online APIs and cleaned up messy local transaction files. In this section, I learned to:

  • Standardize tables: Rename columns for consistency and cast data to the correct types.
  • Handle missing data: Fill gaps using forward-fills for time-series data or medians to avoid skewing the dataset.
  • Clean duplicates and text: Drop duplicate rows and split text strings into separate columns.

Notebook 1: Introduction to NumPy & Pandas

This notebook introduces the fundamentals of NumPy arrays (for vectorised calculations) and Pandas Series/DataFrames (which label indexes).

Part 2 Takeaway: Messy data is the norm. I learned that you cannot just load a dataset and immediately start plotting it. You have to spend a significant amount of time checking for null values, fixing formatting, and making logical decisions on how to fill missing entries without biasing the dataset.
